## ✨ Key Features

* ⏱ **Smart Duration Control:** Configure custom minutes and seconds so typing completes within your designated timeframe.
* ⌨ **Conflict-Free Global Hotkeys:** Integrated with dedicated hotkeys to prevent default OS-level paste collisions.
* ⏸ **Smart Pause & Resume:** Press `ESC` to halt typing and resume later from the exact character index where you left off.
* 📊 **Live Progress Tracking:** Real-time visual percentage display (`0%` to `100%`) directly in the UI.
* 🧹 **Auto-Clear Engine:** Automatically resets and clears the input field upon 100% typing completion.
* 🚀 **Cross-Platform Compatibility:** Native standalone support for Windows, macOS, and Linux.

## ⌨️ Global Shortcuts

| Action | Shortcut Key | Description |
| :--- | :--- | :--- |
| **Start / Resume** | `Alt + Shift + X` | Triggers typing or resumes from paused position |
| **Alternative Start** | `Ctrl + Alt + K` | Secondary trigger for starting/resuming |
| **Pause / Stop** | `ESC` | Immediately pauses execution |

---

## 🚀 How to Use

1. Launch **TypeFlow Desktop Pro**.
2. Paste your target content into the text area.
3. Configure your desired duration using the **Minutes** and **Seconds** inputs.
4. Click **Save & Activate**.
5. Switch to any target program (VS Code, Notepad, Web Browser, Discord, etc.) and place your cursor where you need the text.
6. Press **`Alt + Shift + X`** (or **`Ctrl + Alt + K`**) to initiate typing.
7. Press **`ESC`** at any time to pause; press the shortcut again to resume.
